### SPECS.md — Required sections

Proposal for the `geometry` section:

```yaml
geometry: {
    configuration: …,
    transformation_groups: {'AILERON_RH': ['W\.AIL.*_RH'],
         'AILERON_LH': ['W\.AIL.*_LH'],
         'WING': ["W.*"]},
    infout_groups: {'BODY': ["b_","b\."], 'AILERON': 'W\.AIL.*',}
    }
```

Proposal for the `control_surfaces` section:

```yaml
transform: {'RUDDER': ['r:hr_1:20','s:p_1:50'], 'AILERON': ['r:ha_1:20'], … },
morphing: {'AILERON': ['r:ha_1:20'], 'WING_TIP': ['t:x:50'], … },
```

We dropped the `t_`/`m_` prefixes, separating the operations into
sections instead.

For the `transform` section, group existence must be verified in advance
against the `geometry` section to honour the "fail early" rule. In the
example above, "RUDDER" does not exist.
